What these counts mean

A task class specifies object categories. A template configuration fixes a room and the object models, supports and distractor pool. Multiple configurations may belong to the same class.

Candidates are enumerated model/room combinations, not successful data. Demo and replay counts below are distinct admitted contract configurations in the monitor. A genuine physics-action replay is required before production. Accepted contract configurations and physical/conceptual templates are counted from committed allocations. The dated candidate inventory is a planning snapshot; later reservation revisions may exclude some candidates. These populations are different; they are not a conversion funnel.

## Pitfalls hit tonight

- `runlogs/runpod/smoke/pods.txt` empty after the shutdown → "all 0 pool pods" forever.
- A `cmd1 && cmd2 && nohup x &` line runs the whole `&&` chain in a background subshell: variables exported in it never reach the foreground shell (two launches went out with an empty `--tro`).
- Two `demo-only` launches in the same second share the run id and directory (`0917-213723` holds both the local and the pod dishwasher run; both succeeded).
- Killing a `first_demo.py` wrapper leaves its local `run_isg` child alive on the GPU (kill the `run_isg` pid too).
- Pod `remote.log` is streamed, but `meta.json` only arrives with the final pull.
